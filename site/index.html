Method, stated plainly: concentrations are CAMS modelled data via the Open-Meteo Air Quality API (not ground-station readings — modelled values run smoother than a street-level CPCB station). Indian AQI is computed from PM2.5/PM10 with the CPCB breakpoint formula; hourly values are indicative, daily values use daily-mean concentrations like the official method. "× the WHO guideline" compares PM2.5 with the WHO 2021 24-hour guideline of 15 µg/m³. Window: 2026-10-25 00:00 → 2026-11-02 23:00 IST. Pipeline: API extract → pandas + quality checks → SQLite idempotent upserts → SQL → this page. Code: github.com/dxhanjay/live-aqi-dashboard
